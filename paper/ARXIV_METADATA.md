## Abstract

We give a quaternary length-8 covering code with 27 words and exact covering
radius 4. Three exhaustive verifier paths check all 65,536 ambient words.
Relative to the audited interval `13 <= K_4(8,4) <= 28`, the construction
proves `K_4(8,4) <= 27`. A retained 26-word candidate has exact radius 5 and
five radius-4 holes. No lower-bound improvement or exact value is claimed.
